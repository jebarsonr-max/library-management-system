How C Stores This Record:

  • bookId (4 bytes integer): Primary key
  • title[100] (100 bytes char array): String buffer
  • author[100] (100 bytes char array): String buffer
  • price (4 bytes float): Cost value
  • quantity (4 bytes int): Total physical copies
  • availableQuantity (4 bytes int): Ready to issue

Why We Use Structures in C

1. Heterogeneous Data Grouping

Unlike arrays that can only store elements of the same data type, a C struct allows grouping different data types (e.g., int for ID, char[] for title, float for price) into a single logical entity named Book.

2. Direct Binary File I/O

With structures, an entire book record can be read or written to disk in a single line of code using fwrite(&book, sizeof(struct Book), 1, fp); and fread().

3. Array of Structures

We declare struct Book library[MAX_BOOKS]; to manage up to 200 books dynamically in contiguous memory, enabling fast linear/binary searching and indexed sorting.

4. Pass-by-Pointer Efficiency

When displaying or updating books, passing const struct Book* b via pointers avoids unnecessary memory copying and improves execution speed.

Answer: A structure in C (defined with the struct keyword) is a user-defined data type that allows grouping variables of different data types under a single name.

In this Library Management System, a book has multiple attributes of mixed types (integer ID, text title, text author, float price, integer quantity). A structure binds these related properties together into a single cohesive struct Book entity.

Answer: An array of structures is declared as:

struct Book library[MAX_BOOKS];

It allows storing multiple book records sequentially in memory. We can access the i-th book's attributes using the dot operator (e.g., library[i].bookId, library[i].title).

  • Issue Validation: Before issuing a book, the program verifies if availableQuantity > 0. If it equals 0, the operation is rejected with an "Out of Stock" message.
  • Return Validation: Before returning a book, the program verifies if availableQuantity < quantity. If it is already equal to total quantity, the operation is blocked to prevent extra phantom copies.

The C program uses binary file I/O functions:

  • fopen("library_books.dat", "wb") to open in write-binary mode.
  • fwrite(&bookCount, sizeof(int), 1, fp); to save the record count.
  • fwrite(library, sizeof(struct Book), bookCount, fp); to write all structures in one atomic operation.
  • fread() during startup to reload records from disk into memory.
